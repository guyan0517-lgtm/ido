# 游戏界面优化、功能扩展与桌面软件化实施方案

## 概述

本方案针对近期提出的界面显示、操作便利性、配色柔和度以及独立软件保存需求，进行针对性增量修改与功能接入。

## 详细功能设计

### 一、新建筑耗材明细说明
向玩家明确展示此前新增建筑的具体消耗材料与工期：
- 冰窖：消耗混凝土2、钢材2、石砖4、木板4，施工6步，单次消耗体力2.5，前置建筑为大地窖，建成后提供三十格保鲜容量。
- 扩耕：消耗原木6、草绳4、泥土6、肥料2，施工4步，单次消耗体力2，建成后当前地块栽培地上限提升至三十块。
- 草场：消耗原木6、木板6、杂草10，施工5步，单次消耗体力2.5，前置建筑为扩耕，提供五块自动照料草地，结算自动制作饲料入库。
- 药田：消耗原木4、石块4、泥土4、肥料2，施工4步，单次消耗体力2，专属特殊田块，用于播种草药种子并采收新鲜药草。

### 二、网络字体本地化加载
- 排查外部网络字体加载失败的原因，将字体文件下载并转存至本地静态资源目录。
- 样式表中引用本地相对路径，消除跨域限制与阻断，保证所有设备均能正常渲染该字体。

### 三、莫兰迪柔和主题配色
- 草莓牛奶：白色为主体色，低饱和莫兰迪粉色为点缀色，呈现柔和纯净质感。
- 薄荷巧克力：浅绿与浅棕色组合，采用莫兰迪低饱和调色，温和自然。
- 粉蓝配色：白粉基底搭配低饱和莫兰迪蓝点缀，避免刺眼高饱和。
- 黑白配色：柔和灰白与深灰调和，降低纯黑纯白的生硬对比。

### 四、物资页面生存面板缩小与装备折叠卡头
- 缩减物资页面上方生存状态与环境数据的内边距与字号，提升可视高度。
- 为装备板块增设专属卡头，支持折叠与展开。
- 实时记录折叠状态至本地存储，默认保持打开，用户收起后下次进入依然维持收起。

### 五、高阶武器替换自动存库
- 玩家穿戴装备时，若当前换下的低阶武器满足条件，检测当前地块是否存在已建成的杂物间。
- 若存在杂物间且有空位，自动将替换下的低阶武器存入杂物间储物库中；若无杂物间，则照常保留在背包。

### 六、背包一键整理与仓库同类合并
- 在背包操作区域新增两字按键：整理。
- 遍历背包内物资，只要当前地块的各类仓库中已存在同类物品且尚有空间，自动将背包中对应的同类物资转存至仓库，并整理合并背包内部堆叠。

### 七、岛屿地图弹窗返回层级修正
- 修复地图交互逻辑，当玩家在岛屿地图界面点击具体地块查看详情后，若点击取消或返回，逻辑返回至大地图界面，而非直接退出整个弹窗。

### 八、状态栏显示范围与微缩调整
- 顶部日期、天气、体力等六个状态气泡整体按比例适度缩小，保持精致美观。
- 增加显示控制，仅在第一个分类即探索主页面展示状态栏，切换至生产、设施、物资、交易等分类时隐藏状态栏。

### 九、桌面独立软件化与图标适配
- 配置网络应用清单文件与离线服务脚本，将软件名称设置为：我一定要活下来。
- 将用户提供的角色图裁切处理为标准应用图标，适配安卓与苹果设备的主屏幕桌面显示，支持添加到主屏幕作为独立软件启动运行。

## 关键文件修改规划
- styles.css：调整主题莫兰迪色系、状态栏微缩与按分类显隐、本地字体声明、生存面板紧凑排版。
- src/ui.js：物资装备折叠卡头、背包整理按键、地图返回层级逻辑、主页状态栏判定。
- src/engine.js：武器穿戴降级存库逻辑、背包合并同类项至仓库逻辑。
- manifest.json 与 index.html：配置独立软件启动项、元数据、图标与应用名称。
