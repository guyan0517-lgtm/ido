# 求生游戏深度扩充与细节优化实施计划

## 关键确认

- 水渠消耗基准：对齐水井与抽水站材料梯级。初级水渠消耗石砖与原木，根据连通格数微增；高级水渠升级消耗钢材、砖块与陶土。
- 栽培地分区：三十块田地分为三个卡头，分别命名为前圃、中圃、后圃。
- 饮食一键填入：按键名称确定为昨日。
- 种子一键归拢：按键名称确定为收纳。

## 1. 功能概述

本次升级涵盖视觉舒适度调节、长按连续制造交互、饮食与物资管理效率提升、农业与养殖新产线拓展、水利海渠引流以及超大农场分区视图重构，全方位完善游戏体验。

- 视觉优化：草莓牛奶配色中的主要文本改用柔和莫兰迪深灰，下一天按键改用柔和莫兰迪浅绿，消除生硬感。
- 连续制造：在配方制作、烹饪、加工和添加燃料等按键上接入长按触发逻辑，按下四百毫秒后开启自动连按。
- 饮食筛选与复用：
  - 饮食选择弹窗右上角增加幸福度下拉筛选。
  - 饮食设定卡片右侧新增昨日按键，一键读取前一日饮食搭配，如果物资不足则静默略过，无需弹出打扰窗口。
- 仓储交互：
  - 物资页面的每个物品栏均支持点击卡头折叠为单行，记录收折状态。
  - 种子储存室新增收纳按键，一键将当前地块与背包中的所有种子收入储存室。
  - 背包物品网格改为两行排列，图标等比例缩微，手机端视野更清爽。
- 农业与水产新体系：
  - 药田与草场支持升级为温室，建成后免受酸雨烈日侵袭。
  - 增设渔场，支持通过捕兽笼获取鱼苗、大型捕兽夹获取蟹苗，草场扩建两块玉米田自动制作饲料投喂。
  - 增设水渠，依照地图连通路径计算造价引流海水。初级水渠消耗石砖与原木，每日产出三份海水；后续可升级为高级水渠，消耗钢材、砖块与陶土，每日产出五份海水。
  - 扩建至三十块田后，自动激活前圃、中圃、后圃三组卡头，探索与设施页面均可单选切页。

## 3. 技术架构与数据设计

```
生产制造长按事件 ───► 定时器连续触发 ───► 更新游戏状态并重绘
海渠跨图路径计算 ───► 广度优先寻路 ─────► 核算格数材料建造水渠
水产与玉米饲料 ───► 跨天自动生长结算 ─► 产出鱼肉蟹肉存库
```

- 制造长按逻辑：统一封装长按事件监听，手指抬起或移开时立即清空定时器，平稳连击不丢帧。
- 水渠消耗梯度：初级水渠以石砖3原木3为基础消耗，每跨越一格距离递增石砖1原木1，工期6步；高级水渠升级消耗钢材1砖块2陶土2，工期7步，产出由每日3份提升至5份海水。
- 分区索引映射：将三十块田的数组按十个一组切片，前圃映射一至十号，中圃映射十一至二十号，后圃映射二十一至三十号，切换时只渲染对应十块。
