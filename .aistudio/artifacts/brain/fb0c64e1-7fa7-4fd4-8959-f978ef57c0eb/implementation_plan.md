# 原版网页存档跨域提取与一键迁移方案

## 关键确认

- 适用设备与场景：覆盖手机移动端与电脑端浏览器，全面适配原版网页同源隔离限制。
- 提取方案设计：同时提供书签自动跳转提取与控制台代码复制提取两种途径，提取后自动携带存档回到新网页并自动载入。
- 名称规范：功能名称严格保持两个字，弹窗内操作为提取、复制、导入、导出。

## 1. 功能概述

由于浏览器同源安全策略，新网页无法直接跨站点读取原版网页的本地缓存。本方案通过生成专属轻量书签提取脚本，玩家在原版网页点击书签或地址栏运行后，自动打包原版网页中的求生游戏存档并跳转回新网页，新网页检测到携带的存档数据后自动完成注入与进度刷新。同时保留文本框手动粘贴导入与导出渠道，确保不同手机与电脑浏览器均能百分之百成功转移游戏进度。

## 2. 界面与交互设计

```
原版网页                                新网页
┌───────────────────────┐              ┌───────────────────────┐
│ 原版求生游戏          │              │ 迁移面板              │
│ 点击书签或粘贴提取代码│ ──自动跳转──►│ 自动解析导入标记      │
│ 提取全部本地求生进度  │              │ 写入缓存并刷新游戏进度│
└───────────────────────┘              └───────────────────────┘
```

- 迁移面板优化：
  - 点击设置中的迁移按键后弹出。
  - 第一栏为一键提取：提供一键复制提取脚本按钮。
  - 第二栏为手动导入：提供多行文本框与导入按键。
  - 第三栏为备份导出：提供导出当前存档按键。
- 手机端流转流程：
  - 玩家在新网页迁移面板点击提取，自动将提取脚本复制到剪贴板。
  - 玩家前往原版网页，在地址栏粘贴运行或者添加为书签点击运行。
  - 脚本在原版网页自动抓取全部求生存档字段，编码后直接跳转回新网页。
  - 新网页载入时自动侦测地址栏中的存档标记，自动存入本地存储并清除地址后缀，游戏即刻无缝恢复旧进度。

## 3. 技术实现与数据流

```
原版网页本地存储
       │
       ▼ 执行提取脚本
打包全部求生相关键值数据
       │
       ▼ 携带数据重定向
新网页路由入口解析标记
       │
       ▼ 写入本地存储
完成游戏数据还原与界面重绘
```

- 原版网页关键键值兼容：
  - 提取脚本自动过滤并抓取包含 dropped、survival、DIS 相关的所有本地存储条目。
  - 无论是常规存档、昨日清晨回滚存档还是配置参数均完整保留。
- 新网页自动捕获逻辑：
  - 在页面初始化时监听地址标记。
  - 若检测到携带的导入数据，自动校验并批量写入本地存储。
  - 写入成功后自动恢复页面初始地址并弹出成功提示，游戏状态重新加载完毕。
