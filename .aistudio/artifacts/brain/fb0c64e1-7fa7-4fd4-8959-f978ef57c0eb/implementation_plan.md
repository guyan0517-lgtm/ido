# 界面优化与功能完善实施计划

## 关键确认

- 顶栏按钮布局：移除顶栏显眼的迁移按钮并移入设置面板，顶栏仅保留本日重开与齿轮设置两个按钮，确保横排排列不出现换行折叠。
- 莫兰迪柔和配色：优化草莓牛奶、薄荷巧克、粉蓝、黑白四套配色，全部采用低饱和色调，下一天按钮颜色随主题动态关联。
- 地图取消返回层级：地块确认弹窗点击取消或关闭时，直接退回大地图，不再退出主菜单。
- 状态栏按分类显隐：仅在主页探索分类展示状态气泡，其他分类隐藏，整体等比例微调。

## 1. 功能概述

本次改动针对前期遗留问题进行收尾与细节打磨，使界面视觉柔和舒适，操作流转自然顺畅。

## 2. 界面与交互设计

```
主页顶栏
┌──────────────────────────────────────────────┐
│ DROPPED INTO SURVIVAL                        │
│ 被扔进一个求生游戏   [重新开始本日]  [设置]  │
└──────────────────────────────────────────────┘
                         │
                         ▼ 打开设置面板
┌──────────────────────────────────────────────┐
│ 设置                                         │
│ 配色：[原版] [草莓牛奶] [薄荷巧克] [黑白] [粉蓝] │
│ 存档：[迁移]                                 │
│ 重置：[从头开始]                             │
└──────────────────────────────────────────────┘
```

- 顶栏按钮：重开按钮与设置按钮采用弹性行排布，左右居中，禁止纵向换行。
- 设置面板：收纳原顶栏的存档迁移功能，按键精简为两个字：迁移。
- 本地字体：已下载至本地静态资源库，确保直接加载，避免网络跨域失败。
- 主题配色：
  - 草莓牛奶：白色为主，低饱和莫兰迪粉点缀。
  - 薄荷巧克：浅绿与浅棕搭配，柔和清新。
  - 粉蓝：白与浅粉为基底，低饱和莫兰迪蓝点缀。
  - 黑白：灰白与深灰调和，明暗自然。
  - 下一天按钮：底色与文字颜色深度绑定主题变量，随主题即时联动。
- 地图流转：在移动确认弹窗中点击取消或者关闭弹窗时，视图平滑退回到大地图，方便重新选点。
- 状态栏：进入探索以外的生产、设施、物资、交易分类时自动隐藏，主页显示时微调尺寸保持精致。
- 软件保存：应用清单与离线配置支持独立软件模式，桌面名称为我一定要活下来，图标为指定角色图。

## 3. 架构设计与数据流

```
用户交互 ───► 事件委托 ───► 界面渲染与数据存取
  │
  ├─ 切换主题 ──────────► 更新页面根节点属性并写入本地存储
  ├─ 点击地图取消 ──────► 重新呼出大地图弹窗
  ├─ 装备高阶武器 ──────► 自动将低阶武器置入当地杂货库
  └─ 点击整理 ──────────► 合并背包同类物资至各类仓库
```

- 建筑耗材说明：
  - 冰窖：消耗混凝土2、钢材2、石砖4、木板4，施工6步，单次消耗体力2.5，提供三十格保鲜容量。
  - 扩耕：消耗原木6、草绳4、泥土6、肥料2，施工4步，单次消耗体力2，提升栽培地上限至三十块。
  - 草场：消耗原木6、木板6、杂草10，施工5步，单次消耗体力2.5，结算自动制作饲料入库。
  - 药田：消耗原木4、石块4、泥土4、肥料2，施工4步，单次消耗体力2，用于种植草药与收获药草。
- 武器替换：穿戴高阶武器时，若当前有建好的杂货库且有空位，自动将卸下的低阶武器存入杂货库，无杂货库则进入背包。
- 背包整理：新增整理按键，一键将背包内与仓库已有同类的物资归入仓库，并理顺堆叠。
